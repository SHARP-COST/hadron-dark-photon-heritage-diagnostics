# Hadron-dark-photon-heritage-diagnostics
Theoretical feasibility and computational simulation of dark photons  from meson decays for non-destructive diagnostics of complex and dense materials, using invariant mass spectroscopy.

## Project Overview

The core idea of this project is to link hadron spectroscopy with non-destructive diagnostics of complex and dense materials through the theoretical application of dark photons

Since the existence of dark photons has not yet been experimentally proven, this work will be developed entirely through physical modeling and computational simulations. 

We utilize radiative decays of light mesons as a hypothetical source for producing dark photons, employing invariant mass spectroscopy to model signal reconstruction upon exiting the material.

The primary objective is to build a benchmark simulation framework to calculate how dark photons would convert into standard photons when traversing highly dense or heterogeneous matrices, and to theoretically evaluate how hadronic spectrometers could identify the dark photon decay after passing through the target sample.
